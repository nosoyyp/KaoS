KAOS - versión actualizada

Para publicarla: sustituye los archivos de tu repositorio de GitHub por los de esta carpeta (index.html, manifest.json, sw.js e icon.svg). Después espera unos minutos y recarga la web.

Los datos se guardan en el navegador de cada dispositivo mediante almacenamiento local. No se sincronizan entre dispositivos. Esta versión es una base funcional y puede necesitar mejoras tras probarla.
